# BlazBlue Entropy Effect Community Hub

## The idea

An unofficial community website where *BlazBlue Entropy Effect* players share builds, explain tactics, teach combos, and post recordings of their runs. Players can browse by character, see how a build or combo works in a real run, and ask the author questions in the comments. [Official game listing](https://store.steampowered.com/app/2273430/BlazBlue_Entropy_Effect/)

The main goal is to help players find something they can try on their next run. A newcomer might look for an easy combo or a build with flexible upgrade choices. An experienced player might share an advanced sequence, a boss tactic, or a speedrun route.

## What players can share

| Post type | What the author shares |
| --- | --- |
| Build | The character, key upgrade and tactic choices, how they work together, and what to pick if a key upgrade doesn't appear. |
| Tactic or guide | How to handle a boss, enemy, or part of a run, with steps and notes on when the advice applies. |
| Combo | The character, inputs in order, timing or positioning notes, and any required upgrades. The author can upload a clip to show the sequence. |
| Speedrun | A directly uploaded run recording, the character, the run time, the category, and any route notes the author wants to share. Times are self-reported. |

Posts include a title and description. Authors can add the game version and difficulty where relevant so readers can tell whether the advice applies to their runs.

## How players find and discuss posts

A player picks their character, filters for combos, and opens a post with a written input sequence and a clip. They watch the timing, try it in-game, and reply to ask how to adjust the combo when an enemy is airborne. The answer stays with the post for the next player who has the same question.

- Visitors can read public posts, watch videos, search by keyword, and filter by character and post type.
- Signed-in players can publish and edit their own posts, upload clips or full speedrun recordings, and comment or reply on a post.
- Each signed-in player can like or dislike a post and change or remove their reaction. Players can report posts and comments for moderator review.

## Proposed page layouts

### Shared navigation

The header links to **Home**, **Characters**, and **Browse**, with a **Create post** button and a **Sign in** or account button. The account menu links to **My posts**. On a phone, the same navigation fits in a compact menu, and page content stacks in reading order.

### Home

The first screen shows a short description, a search box, and a **Choose a character** button. Below that, a character grid gives players a direct way into a character page. A **Recent posts** section previews what people are sharing. Each preview shows the title, character, post type, and a clip thumbnail when a video is available. A player who already knows their character can reach its posts without scrolling through the feed.

### Character directory

A searchable grid shows each character's name and portrait where artwork is available. Selecting a card opens that character's page. The directory is useful when a player wants to explore the roster or switch to another character.

### Character page

The character name sits above tabs for **All**, **Builds**, **Tactics**, **Combos**, and **Speedruns**. The selected tab shows matching posts with their title, author, and reaction and comment counts. The list can be sorted by **Newest** or **Most liked**. A **Create post** button opens the editor with this character already selected. An empty tab shows a short message and an invitation to share the first post.

### Browse and search results

The search box sits above filters for **Character** and **Post type**, followed by the results. This is where a player can look for a boss tactic across several characters or browse all speedruns in one place. On desktop, filters can sit beside the list. On a phone, a **Filters** button opens the options above the results. If nothing matches, the page offers to clear the filters while keeping the search term.

### Post detail

Every post opens with its title, author, and character, followed by the information the reader came for. The page uses one shared layout with a different main section for each post type.

| Post type | What the reader sees first |
| --- | --- |
| Build | A short description of how the build plays, followed by its key choices, what to prioritize, and alternatives. |
| Tactic or guide | The situation the tactic applies to, followed by steps the reader can try. |
| Combo | The clip, if attached, and a numbered input sequence with timing notes. On desktop they can sit side by side. On a phone the sequence follows the clip, or appears first when there's no clip. |
| Speedrun | A video player and a run summary with the character, category, and self-reported time, followed by any route notes. |

Like and dislike controls sit above the discussion, where players can comment or reply. Videos play on demand. A visitor who chooses a signed-in action gets a sign-in prompt and returns to the same post afterward.

### Create or edit a post

The editor starts with **Post type** and **Character**, then shows the fields for that type. A combo asks for the input sequence and offers an optional clip upload. A speedrun asks for the time, category, and recording. The upload section shows accepted formats and limits before file selection, then displays progress and a retry option if the upload fails. The author can retry without re-entering the post text. Publishing opens the public post so the author can share its link.

### Sign in and My posts

The sign-in screen has a clear path to create an account and returns the player to the post or editor they came from. **My posts** shows the player's own published posts with **View** and **Edit** actions. It gives returning contributors a direct way to update a build after a patch or correct a combo input.

### Moderator report queue

Moderators see a private list of reported posts and comments. Each entry shows the reason, links to the content in context, and offers actions to dismiss the report or remove the content.

## Proposed first release

Make character pages the main way to browse. A general feed could make recent posts easier to spot, and a video-first gallery could make clips easier to discover. Character pages keep written guides and videos together for the player who already knows whom they want to play.

The first release covers all four post types, direct uploads, search and filters, reactions, and discussion on each post. Set separate upload limits for short combo clips and full speedruns, and show those limits before a player selects a file. Verified speedrun rankings, a dedicated forum, and an interactive build planner can be considered after launch.

The first release succeeds if a new visitor can find a relevant build or combo, understand how to try it, and return with a question or a contribution of their own.
